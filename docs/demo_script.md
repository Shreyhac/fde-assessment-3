# Timed demo script (about 5 minutes)
The Loom recording follows this script. Because the live Anthropic run is already complete, the demo shows the saved live decisions through the app's **Recorded live run** view: real model output, clearly labelled, with no new API spend and no network dependency during recording. Editing a request and running it offline is shown only as a product-flow demonstration, and is labelled as such on screen.

**0:00-0:30 - Problem and guarantee.** "Companies get ad-hoc software purchase requests. This copilot drafts an evidence-grounded recommendation, but a human always decides. The guarantee: it can advise, never buy, approve, change a budget, or accept terms."

**0:30-1:00 - Architecture.** Show `docs/architecture.svg`. "The model retrieves evidence through four read-only tools and submits structured advice. Code re-runs any check the model skipped, applies the deterministic controls - thresholds, freshness, conflicts, security, privacy, legal - and locks clarify and manual-review routes. Architecture A is one agent; B adds a policy reviewer over the analyst's advice and the computed controls."

**1:00-2:30 - Recorded live run.** Open the app, switch to "Recorded live run". "These are real decisions from the completed live evaluation - 72 decisions on Claude Sonnet 5.5, 182 physical API calls, a $1.8984 usage estimate." The selector lists case keys from the run. Walk three: the EXT-10 / REQ-1010 run (SignFlow Training Pack - clean approval_review), PUB-05 / REQ-1006 (injected "CFO-approved" instruction - clarify with prompt_injection_detected), EXT-07 / REQ-1004 (customer PII with out-of-region storage - manual_review with Security, Privacy and Legal). For a reuse_review example, REQ-1001 (SignFlow Add-on) routes to reuse_review in every recorded run. Point at evidence IDs, approvals, risk flags, the model's tool-call list and the human-review line in each.

**2:30-3:30 - Controls under pressure.** Show a request whose department has no budget record (requester E007, Go To Market): "The old code asked the requester for their budget instead of reading the record. Now a missing budget record flags budget_unverified, code adds Finance and routes to manual review." Then edit a request in offline mode (labelled as a deterministic preview): move the amount across a threshold, watch approvals change; stale results clear on edit.

**3:30-4:30 - A/B evidence.** Show the comparison summary and `validation/anthropic_toolcalling/`. "Both architectures hit 30/30 expected final routes with every control preserved. The model's own route matched in 27/30 runs per architecture; the three corrections were the injection case, where the prompt named two triggers without a precedence and code's clarify-first rule won. B used 1.5 times the model calls (90 vs 60) and about 1.75 times the latency, its reviewer never once changed the analyst's route in 36 runs, so I ship A."

**4:30-5:00 - Limits and close.** "Synthetic data, ten requests, one provider, manual semantic review. No purchasing exists in the product. Full memo and reproducible harness are in the repository."
